# Meter map window

Edit a meter profile, read a register map out of a manual, send it to a gateway.
One page, shared by the browser HMI and the Android app (which bundles these exact
files into its APK and shows them in a WebView), so the two cannot drift apart.

```
index.html  style.css  app.js          the page
profile.js                              profile model: validate, decode, wire encoding   (port of tools/meterprofile.py)
topics.js fleet.js transport.js         MQTT topics, what the page knows, how it talks (MQTT-over-WebSocket or the Android bridge)
uploader.js                             the acked profile_begin/regs/meta/commit sequence
zip.js docx.js xlsx.js pdftext.js       document readers (PDF via vendor/pdf.min.js, loaded only when a PDF is chosen)
tablemap.js importer.js                 register-table heuristics, review rows, draft profile
shipped.js                              GENERATED by tools/gen_ui_profiles.py
tests/                                  node --test, plus ui_smoke.js / hmi_smoke.js (Playwright)
```

Open `meter-map/index.html` from wherever `browser-hmi/` is served. It uses the same
broker settings as the HMI (`config.js`, or `?wss=&user=&pass=`); `?modem=gw-01` picks
a modem.

## Tests

```bash
node --test tests/*.test.js                       # pure logic, 43 tests
NODE_PATH=$(npm root -g) node tests/ui_smoke.js   # the real page, headless Chromium, mock gateway
NODE_PATH=$(npm root -g) node tests/hmi_smoke.js  # the main HMI page follows a profile
```

`tests/fixtures/make_fixtures.py` regenerates the sample manuals (they are invented).

## Safety notes

* Uploaded documents are untrusted. Their text is only ever put on the page with
  `textContent` / `value`, never `innerHTML`, and PDF.js runs with `isEvalSupported:false`.
* Nothing leaves the device: documents are parsed locally; only a profile you choose
  to send goes to your own broker.
* The Android bridge exposes four methods (`send`, `snapshot`, `connected`, `shareText`)
  and the WebView cannot read files other than the bundled assets.
